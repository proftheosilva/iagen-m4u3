# Módulo 4 · Unidade 3 — Construção de Agentes Inteligentes

Página didática interativa de apoio aos alunos do **Curso de Formação em IA Generativa**.

## Sobre esta Unidade
Esta unidade apresenta como construir agentes inteligentes prontos para produção: autonomia real vs. teatral, decomposição e replanejamento, controle de estado e *checkpoints*, gestão da janela de contexto e combate ao ruído, arquitetura em 5 camadas, orquestração em grafo (nós, arestas e ciclos controlados), frameworks (LangChain, LangGraph, AutoGen) e observabilidade.

### Recursos da Aplicação
- **Simulador Visual Dinâmico**: Fluxo animado de orquestração em grafo com checkpoints e idempotência.
- **Conteúdo Interativo**: Tópicos com explicações *Do Zero*, *Na Prática*, *Atenção / Risco* e *Ponto-chave*.
- **Quiz de Fixação**: 10 perguntas com feedback imediato e explicação.
- **Jogo da Memória**: Combinação de conceitos e definições da unidade.

## Stack Tecnológica
- **Next.js** (App Router com `output: "export"` para deploy estático)
- **Tailwind CSS**
- **Lucide React**

## Como executar localmente
```bash
npm install
npm run dev
```

## Publicação na Vercel
Importe o repositório no GitHub, selecione o diretório `MOD4/U3-WEB` como **Root Directory** e faça o deploy (sem necessidade de banco de dados ou variáveis de ambiente).
